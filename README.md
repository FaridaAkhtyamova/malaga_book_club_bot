# Бот книжного клуба Малаги

Бот живёт в Telegram-группе клуба. Раз в месяц он открывает сбор книг на **следующий** месяц, участники предлагают названия, потом админ запускает голосование.

Пример: в сентябре предлагаем книги на октябрь, потом голосуем.

---

## Как предложить книгу (участники)

Пока сбор открыт.

**В группе клуба** запостите карточку с тегом (название и число страниц):

```
#выбор_книги Имя Розы, 500
```

Бот добавит книгу в список на голосование. Тег можно писать в любом регистре.

**В личке с ботом** — поиск по каталогу: `/suggest` или `/suggest Дюна`, выбрать из списка. Если книги нет — кнопка **«Моей книги нет — добавить самой»**. Перед отправкой бот покажет карточку: **Отправить в группу** или **Отмена**.

Отменить поиск в личке: `/cancel`.

Если бот пишет «предложения ещё не открыты» — админ ещё не запустил сбор.

---

## Как закрыть сбор и сделать голосовалку (админ)

Когда книг достаточно (минимум две):

```
/start_vote
```

Бот закроет предложения и опубликует в группе опрос(ы). Опросы **неанонимные**. В Telegram в одном опросе максимум 10 вариантов: если книг больше, будет несколько опросов. Голосовать можно в каждом.

Потом `/suggest` уже не сработает, пока админ снова не откроет сбор. В обычном режиме повторно открыть тот же месяц нельзя (см. debug ниже).

---

## Как выбрать дату встречи (админ)

Когда книга уже выбрана:

```
/start_meeting_poll
```

Бот опубликует в группе **один** неанонимный опрос: 10 дней начиная с послезавтра (`14, понедельник`), плюс «не прочитала» и «пропущу». Можно отметить несколько вариантов и добавить свой. Название книги пока заглушка — победитель прошлого голосования ещё не подключён.

---

## Команды для всех

| Команда | Что делает |
|---|---|
| `/start` | Приветствие, регистрация в боте |
| `/suggest` | Поиск книги в личке с ботом |
| `/suggest Название` | То же, сразу с названием |
| `/cancel` | Отменить ввод названия |

---

## Команды для админа

Админ — тот, чей Telegram id записан в настройках бота.

Их можно писать в группе или в личке с ботом (кроме первой).

| Команда | Что делает |
|---|---|
| `/set_group` | Запомнить эту группу как клубную. **Только из группы**, один раз |
| `/open_suggestions` | Открыть сбор книг на следующий месяц и написать анонс в группу |
| `/start_vote` | Закрыть сбор и опубликовать голосовалки |
| `/start_meeting_poll` | Опрос дат встречи по выбранной книге (пока заглушка названия) |
| `/set_suggest_day 15` | Каждый месяц 15-го автоматически открывать сбор (день от 1 до 28) |
| `/set_vote_day 25` | Каждый месяц 25-го автоматически запускать опросы (должен быть позже дня сбора) |
| `/cycle_status` | Что сейчас: группа, дни, месяц, сколько книг уже предложено |

Анонсы по расписанию уходят в 10:00 по Малаге. Не хотите ждать — `/open_suggestions` и `/start_vote` можно жать руками в любой момент.

---

## Один раз при запуске

1. Добавить бота в группу и дать ему права **админа** (без этого неанонимные опросы не отправятся).
2. В [BotFather](https://t.me/BotFather) → ваш бот → **Group Privacy** → **Turn off**. Иначе бот не увидит сообщения с `#выбор_книги`.
3. В группе: `/set_group`.
4. Когда пора собирать книги: `/open_suggestions`.
5. Когда пора голосовать: `/start_vote`.

---

## Тесты: debug mode

В `.env` добавьте:

```
DEBUG=true
```

Перезапустите бота. В логе будет `DEBUG mode is on`.

Тогда `/open_suggestions` после `/start_vote` снова открывает сбор и сбрасывает список книг — можно гонять цикл туда-сюда без смены месяца.

На проде поставьте `DEBUG=false` или уберите строку. Код менять не нужно.
