# Бот книжного клуба Малаги

Бот живёт в Telegram-группе клуба и в личке. В группе он **только публикует** анонсы, опросы, карточки и приглашения — на сообщения и команды там не отвечает. Общаться с ботом нужно в личке.

Пример: в сентябре предлагаем книги на октябрь, потом голосуем.

---

## Как предложить книгу (участники)

Пока сбор открыт.

**В группе клуба** запостите карточку с тегом `#выбор_книги`:

```
📖 #выбор_книги
Название книги
Автор
500 стр.

Краткое описание книги
```

После тега — название, затем автор. Число страниц бот ищет в любой строке со словами «стр» / «страниц». Кто предложил, берётся из сообщения в Telegram. Обложку можно прикрепить картинкой. Бот не отвечает на карточку в группе и не добавляет её в опрос сразу: перед `/start_vote` админам в личку уйдёт очередь на проверку. Если бот плохо разобрал поля, админ поправит их. Тег можно писать в любом регистре. Сообщения самого бота (после `/suggest` в личке) в эту очередь не попадают.

**В личке с ботом** — поиск по каталогу: `/suggest` или `/suggest Дюна`, выбрать из списка. Если книги нет — кнопка **«Моей книги нет — добавить самой»**. Перед отправкой бот покажет карточку: **Отправить в группу**, **Искать заново** или **Отмена**.

Отменить текущий ввод: `/cancel` (поиск, проверка карточки, опрос дат, создание встречи).

Если в личке бот пишет «предложения ещё не открыты» — админ ещё не запустил сбор.

## Как закрыть сбор и сделать голосовалку (админ)

Когда книг достаточно (минимум две):

```
/start_vote
```

Если в группе за время сбора появились ручные карточки с тегом, бот **не** публикует опросы, пока админ в личке не нажмёт «В голосование», «Исправить» или «Пропустить». После пустой очереди команду нужно вызвать ещё раз.

Бот закроет предложения и опубликует в группе опрос(ы). Опросы **неанонимные**. В Telegram в одном опросе максимум 10 вариантов: если книг больше, будет несколько опросов. Голосовать можно в каждом.

Когда время вышло:

```
/close_vote
```

Бот остановит опросы и посчитает голоса. Если победитель один — в группу уйдёт сообщение с выбранной книгой **и сразу опрос дат встречи**. Если две (или больше) книги с одинаковым максимумом — опубликуется второй тур только с ними; его тоже закрывают `/close_vote`. Если опрос дат не отправился, его можно повторить командой `/start_meeting_poll`.

Если опросы уже идут (или книга уже выбрана), но список надо собрать заново **без нового сбора предложений**:

```
/reset_vote
```

Бот закроет текущие опросы за книгу и за даты (победителя не выбирает) и сразу опубликует новые голосовалки с книгами этого цикла **с 1-го числа месяца, когда сбор открыли**. Старые предложения до этой даты в опрос не войдут.

Если голосование за книгу сделали вручную в Telegram (не через бота), `/start_meeting_poll` всё равно можно запустить — закрывать `/close_vote` для этого не нужно.

Потом `/suggest` уже не сработает, пока админ снова не откроет сбор. В обычном режиме повторно открыть тот же месяц нельзя (см. debug ниже).

## Как выбрать дату встречи (админ)

Опрос дат можно открыть в любой момент текущего цикла, даже если голосование за книгу ещё идёт или его сделали вручную в Telegram:

```
/start_meeting_poll
```

После успешного `/close_vote` с одним победителем опрос дат уходит в группу сам. Если его не было, команда выше запускает его вручную.

Это **один** неанонимный опрос: 10 дней начиная с послезавтра (`14.09`), плюс «не прочитала» и «пропущу». Можно отметить несколько вариантов и добавить свой. Если книга уже выбрана ботом, она будет в заголовке; иначе бот сначала спросит название. Отмена: `/cancel`.

Когда время вышло:

```
/close_meeting_poll
```

Бот остановит опрос и посчитает голоса за дни (варианты «не прочитала» и «пропущу» в победителя не идут). Если день один — в группу уйдёт сообщение с книгой и датой, админам в личку — напоминание создать событие через `/create_meeting`. Если несколько дней с одинаковым максимумом — второй тур только с ними; его тоже закрывают `/close_meeting_poll`.

---

## Как создать приглашение в календарь (админ)

Когда дата уже выбрана (`/close_meeting_poll`), бот её подставит. Если опроса дат не было — спросит дату (`25.09` или `25.09.2026`):

```
/create_meeting
```

Если книга выбрана ботом, она попадёт в заголовок и бот спросит только время начала (`19:00`). Если голосование за книгу пропустили — сначала спросит название. В группу уйдёт файл `event.ics`. Часовой пояс — Малага. Отмена: `/cancel`.

## Команды для всех

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и регистрация (**только в личке**) |
| `/help` | Список команд (личка) |
| `/suggest` | Поиск книги в личке с ботом |
| `/suggest Название` | То же, сразу с названием |
| `/cancel` | Отменить поиск, проверку карточки, опрос дат или создание встречи |

---

## Команды для админа

Админ — администратор или создатель **привязанной** группы клуба (`/set_group` в этой группе или `GROUP_CHAT_ID` в `.env` для первого клуба). Список из `.env` больше не используется.

Все команды — **в личке с ботом**. В группе бот на них не отвечает (кроме одноразовой привязки `/set_group` и `/set_suggest_topic`). Чтобы бот мог писать в личку (карточки на проверку, напоминание про встречу), каждый админ один раз пишет боту `/start` в личке.

| Команда | Что делает |
|---|---|
| `/set_group` | Запомнить **эту** группу как клубную. **Только из группы** |
| `/set_suggest_topic` | Привязать топик предложений (вызвать из ветки). Сброс: `/set_suggest_topic clear` |
| `/open_suggestions` | Открыть сбор книг на следующий месяц и написать анонс в группу |
| `/start_vote` | Проверить ручные карточки из группы, затем закрыть сбор и опубликовать голосовалки |
| `/close_vote` | Закрыть опросы, выбрать книгу или запустить второй тур при ничьей |
| `/reset_vote` | Закрыть текущие опросы и открыть голосование заново с книгами с 1-го числа месяца сбора |
| `/start_meeting_poll` | Открыть опрос дат (спросит книгу, если её нет) |
| `/close_meeting_poll` | Закрыть опрос дат, выбрать день или второй тур при ничьей |
| `/create_meeting` | Спросить дату (если нет опроса), книгу (если нет) и время, опубликовать приглашение (файл `.ics` и кнопки календаря) |
| `/set_suggest_day 15` | Каждый месяц 15-го автоматически открывать сбор (день от 1 до 28) |
| `/set_vote_day 25` | Каждый месяц 25-го автоматически запускать опросы (должен быть позже дня сбора) |
| `/cycle_status` | Что сейчас: группа, дни, месяц, сколько книг уже предложено |
| `/month_book` | Выбранная книга месяца |

По расписанию в **10:00 по Малаге**: в день сбора бот открывает предложения, в день голосования публикует опросы (если нет карточек в очереди на проверку). Закрывать опросы всегда вручную. Не хотите ждать — в личке `/open_suggestions` и `/start_vote` можно жать в любой момент.

## Один раз при запуске

1. Добавить бота в группу и дать ему права **админа** (неанонимные опросы, топики, список админов группы).
2. В [BotFather](https://t.me/BotFather) → ваш бот:
   - **Group Privacy** → **Turn off**. Иначе бот не увидит сообщения с `#выбор_книги`.
   - **Edit Bot** → имя, описание (до 512 символов) и about (до 120) — для каждого клуба свои, код их не перезаписывает.
3. Админ группы в этой группе: `/set_group`. При желании топик предложений: `/set_suggest_topic` из нужной ветки. Можно заранее прописать `GROUP_CHAT_ID` в `.env` — тогда шаг с `/set_group` не обязателен. Чтобы бот работал ещё в одной группе (например, тестовой), вызовите `/set_group` и там; в личке при необходимости `/clubs` выберет, с какой группой работать.
4. Каждый админ пишет боту `/start` в личке.
5. Когда пора собирать книги: в личке `/open_suggestions`.
6. Когда пора голосовать: в личке `/start_vote` (если были ручные карточки — сначала разберите их в личке).

## Тесты: debug mode

В `.env` добавьте:

```
DEBUG=true
```

Перезапустите бота. В логе будет `DEBUG mode is on`.

Тогда `/open_suggestions` после `/start_vote` снова открывает сбор и сбрасывает список книг — можно гонять цикл туда-сюда без смены месяца.

На проде поставьте `DEBUG=false` или уберите строку. Код менять не нужно.

## Запуск в облаке (Docker)

На сервере в каталоге репозитория должен лежать `.env` (как в `.env.example`). `DB_HOST=localhost` в файле нормально: контейнер бота сам ходит в Postgres по имени сервиса `postgres`.

```bash
sudo systemctl enable --now docker
sudo apt-get update && sudo apt-get install -y docker-compose-plugin
docker compose up -d --build
docker compose ps
docker compose logs -f bot
```

Поднимаются Postgres и бот. После ребута сервера контейнеры встанут сами (`restart: unless-stopped`).

Локальный `python main.py` остановите: два процесса с одним токеном конфликтуют в Telegram.
